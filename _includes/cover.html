{% comment %} Renders a book cover. If the book has a `cover:` filename in _data/books.yml, that image is used. If it doesn't — which is the case until the artwork exists — it draws a typographic binding instead: cloth, gilt rules, the title set in Garamond. Nothing is missing from the page while you wait for the real thing. Set `cloth:` on a book to choose the binding colour: burgundy (default), forest, indigo, or tan. Set `era:` to print a year beneath the cover — the year carried on that book's spine. Omit it and nothing is drawn. Pass `href=` to make the cover itself a link to the book: {% include cover.html book=b href=url %} Only the picture becomes clickable — the year beneath it stays plain text, so it doesn't pick up link colour and an underline. A cover with no href renders exactly as it always did, which is what the book's own page wants: a cover that links to the page you are already on is a small cruelty. {% endcomment %} {% assign b = include.book %} {% assign href = include.href %} {% if href %}{% endif %} {%- if b.cover -%} {%- else -%}
